# Bobber Forever

A small button for fishing in World of Warcraft: Forever.

Click it before you start fishing and it turns the sound effects up, mutes the music and ambience, and keeps the game making sound while it's in the background. That way you hear the bobber splash even with other things going on. Click it again and your own sound settings come back exactly as they were.

If the game closes while it's on, your settings are put back the next time you log in.

The button shows the fishing pole when the sound is on, and a crossed-out grey pole when it's off. Drag it with the right mouse button to move it.

## Commands

| Command | What it does |
| --- | --- |
| `/bobber toggle` | Fishing sound on or off |
| `/bobber lock` | Lock or unlock the button |
| `/bobber reset` | Put the button back in the middle of the screen |
| `/bobber show` | Show the button |
| `/bobber hide` | Hide the button |

Translated into the ten WoW client languages. Other languages use English.

Made for World of Warcraft: Forever 1.60.1 (`Interface: 16001`).

## Installation

1. Extract the `BobberForever` folder into `World of Warcraft\_classic_beta_\Interface\AddOns\`
2. Restart the game.
3. Check that it's enabled in the AddOns list on the character screen.
